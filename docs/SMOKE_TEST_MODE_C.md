## 自动编排（模式 C）手工冒烟清单

前置：后端与前端已启动（或通过 Docker 启动），并能正常访问 Web。

### 1. 项目初始化（语料准备）

- 进入左侧「项目初始化」
- 选择目录并注册（或手动输入路径注册）
- 点击「初始化（转换 + 索引）」并等待完成
- 预期：
  - 初始化日志中出现「文档转换」「索引与分块」完成
  - 返回「分析」后，该项目出现在「选择已初始化项目」下拉中

### 2. 分析（自动编排）

- 在分析页选择已初始化项目
- 输入：`请对当前项目做一次完整审查，并输出审查结果。`
- 点击开始
- 预期：
  - 流程区出现 Agent 阶段（routing/executing 等）
  - 输出区出现流式内容
  - 产物区能看到「片段索引.md」「审查结果.md」对应的下载链接/按钮（居左）

### 3. 追问（多轮）

- 在同一会话继续输入追问：`请解释上面提到的最高风险点，并给出可执行的缓解建议。`
- 点击开始
- 预期：
  - 能继续输出（followup 或重新 analyze 由编排决定）
  - 会话消息流中保留多轮对话

### 4. 语料过期提示（仅供参考）

- 通过项目设置/数据库方式清空该项目 chunks（或删除/移动 md_out 目录后重启后端）后\n  重新打开该会话历史
- 预期：
  - 顶栏提示「语料已过期，历史会话仅供参考」\n  - 开始按钮禁用（无法继续审查/追问）

### 5. 会话历史与删除

- 打开「会话历史」，选择会话打开\n- 点击右侧删除按钮并确认
- 预期：
  - 会话删除成功\n  - 当前会话若被删除回到空白分析页\n
