# AI-KA（ProjectLens）用户手册

面向在浏览器中使用 Web 界面完成「项目初始化（转换+索引）→ 自动编排审查/追问」的用户。

## 1. 产品能做什么

将项目目录下的业务文档（经 docs2md 转为 Markdown 后）按关注点进行关联审查，输出结构化 Markdown 结论，并可在文末查看**片段与来源索引**（对应原文文件与行号）。

## 2. 选择项目与路径

本产品将流程拆为两步：

1. **项目初始化**：注册项目目录，并执行「文档转换（docs2md）→ 索引与分块（index-md）」使语料可用于审查。
2. **分析**：在流式对话窗口中基于已初始化的项目进行审查与多轮追问（不再在分析页选择本地目录）。

- **本机目录**：若后端运行在本机桌面环境，可在「项目初始化」中使用目录选择器回填绝对路径。
- **手动路径**：在 Docker 或远程访问时，请在「项目初始化」输入**后端进程可见**的目录路径（例如容器内已挂载路径）。

## 3. 关注点与审查技能包

- **审查技能包**：关注点与「组合使用建议」来自当前活动包下的 `**review_domain.md`**（Markdown 结构与仓库根模板 `**default_skills.md**` 一致）。包根目录默认为 `$AIKA_REPO_ROOT/review_skill_packages`，可用 `**AIKA_REVIEW_SKILL_PACKAGES_ROOT**` 覆盖；当前包 id 保存在 `**app_settings.md**` 的 `**active_skill_package_id**`。界面 **设置 → 审查域** 可切换包并显示当前 `review_domain.md` 路径。
- **关注点**：在 `review_domain.md` 中用 `### focus:<id> | <展示名称>` 定义；正文为该关注点的审查 Prompt。可在 **设置 → 审查域 → 关注点** 中编辑，或整文件校验/导入。
- **「组合使用建议」表格（固定五列，可选）**：同一文件中可包含二级标题 **「组合使用建议」** 与 **五列** Markdown 表（`评审节点` | `推荐组合的关注点` | `审查角色` | `审查目标与原则` | `输出要求`）。当前版本的分析页不要求用户选择预设；系统会根据输入自动路由关注点组合，但该表格仍可用于维护推荐组合与文案资产。

## 4. 设置说明


| 项        | 说明                                                                                     |
| -------- | -------------------------------------------------------------------------------------- |
| chunk 上限 | 参与本次模型分析的片段数量上限（越大上下文越长，费用/耗时通常越高）。                                                    |
| **分块方式** | **空行分块**：与升级前一致，按空行切段再按字数装箱。**标题与结构感知**（`.md`）：按 `#`/`##` 等标题与代码围栏分节再装箱；`.txt` 仍为空行管线。 |
| 不解析图片    | 转换阶段是否跳过文档内图片解析。                                                                       |
| **审查域**  | **关注点** 与 **预设组合** 子页签见上文第 3 节；支持从文件校验/导入并写回当前活动包的 `review_domain.md`。                 |
| Model    | 文本链路与 VL 链路可分别配置 Provider、Base URL、模型名与 API Key。                                       |


**重要**：修改**分块方式**并保存后，必须重新执行「索引与分块」（或全流程中的索引步骤），否则分析仍基于旧分块结果。保存后若策略有变化，界面会提示重新索引。

## 5. 执行全流程

1. 在左侧进入「项目初始化」，选择目录/填写路径并注册项目。
2. 点击「初始化（转换 + 索引）」完成语料准备。
3. 切回「分析」视图，选择项目，在输入框描述你的目标与关注点（可选），点击发送开始审查。
4. 流程区会显示任务说明与里程碑日志；完成后生成审查结果与下载入口。

## 6. 阅读结果与导出

- 正文中引用证据时请使用**片段编号**，并与块头中的文件、章节信息一致。  
- 文末 **「片段与来源索引」** 表格列出本次送入模型的片段序号、文件路径、章节（空行策略下可能为「—」）、行号范围。  
- 使用结果区的「审查报告」可下载当前结果。

## 7. 常见问题

**片段编号和文件是什么关系？**  
编号与本次分析实际送入模型的片段顺序一致；索引表与正文前的块头共同标明来源文件与行号。

**Docker 下选不了本机文件夹？**  
请使用手动路径，并确保该路径在容器内已正确挂载。

**改过分块方式但结果没变？**  
请重新执行索引；仅改设置不会自动重扫大目录。
