# AI-KA（ProjectLens）用户手册

面向在浏览器中使用 Web 界面完成「文档转换 → 索引与分块 → 模型审查」的用户。

## 1. 产品能做什么

将项目目录下的业务文档（经 docs2md 转为 Markdown 后）按关注点进行关联审查，输出结构化 Markdown 结论，并可在文末查看**片段与来源索引**（对应原文文件与行号）。

## 2. 选择项目与路径

- **本机目录**：若后端运行在本机桌面环境，可使用「选择项目」弹出系统文件夹对话框，回填绝对路径。
- **手动路径**：在 Docker 或远程访问时，请在输入框填写**后端进程可见**的目录路径（例如容器内已挂载路径）。
- 确认页面显示已识别项目名称后再执行流程。

## 3. 关注点与预设

- 在设置中维护关注点（名称 + 审查 Prompt）；可从 `rules.md` 导入。
- 首页多选关注点；若存在预设或「组合建议」，可一键套用。

## 4. 设置说明

| 项 | 说明 |
|----|------|
| chunk 上限 | 参与本次模型分析的片段数量上限（越大上下文越长，费用/耗时通常越高）。 |
| **分块方式** | **空行分块**：与升级前一致，按空行切段再按字数装箱。**标题与结构感知**（`.md`）：按 `#`/`##` 等标题与代码围栏分节再装箱；`.txt` 仍为空行管线。 |
| 不解析图片 | 转换阶段是否跳过文档内图片解析。 |
| Model | 文本链路与 VL 链路可分别配置 Provider、Base URL、模型名与 API Key。 |

**重要**：修改**分块方式**并保存后，必须重新执行「索引与分块」（或全流程中的索引步骤），否则分析仍基于旧分块结果。保存后若策略有变化，界面会提示重新索引。

## 5. 执行全流程

1. 选择项目路径与关注点。  
2. 点击「执行」：依次 **文档转换**（docs2md）→ **索引与分块** → **模型分析**。  
3. 流程区顶部会显示本次任务说明；各步骤日志在里程碑中展开查看（进行中默认展开，完成后默认折叠，可手动切换）。  
4. 成功后流程区会出现 **「已完成。」**，右侧生成审查结果 Markdown。

## 6. 阅读结果与导出

- 正文中引用证据时请使用**片段编号**，并与块头中的文件、章节信息一致。  
- 文末 **「片段与来源索引」** 表格列出本次送入模型的片段序号、文件路径、章节（空行策略下可能为「—」）、行号范围。  
- 使用「导出 md」可下载当前结果。

## 7. 常见问题

**片段编号和文件是什么关系？**  
编号与本次分析实际送入模型的片段顺序一致；索引表与正文前的块头共同标明来源文件与行号。

**Docker 下选不了本机文件夹？**  
请使用手动路径，并确保该路径在容器内已正确挂载。

**改过分块方式但结果没变？**  
请重新执行索引；仅改设置不会自动重扫大目录。
