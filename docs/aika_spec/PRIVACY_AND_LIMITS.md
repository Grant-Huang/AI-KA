# 隐私红线与注入上限

## 禁止写入记忆的内容

- 密钥、令牌、密码、连接串。
- 身份证、银行卡等可直接识别个人的数据。
- 未经脱敏的完整合同/病历等全文（`reference` 仅摘要或路径 + 短摘录）。

## 注入上限（默认值，可在代码中集中配置）

| 项 | 建议上限 |
|----|----------|
| `MEMORY.md` 索引 | 4000 字符 |
| 单条记忆文件注入正文 | 6000 字符 |
| 每轮分析注入记忆条数 | 5 条 |
| 记忆片段进入 system prompt 总预算 | 12000 字符 |

超出时按相关性得分截断最后一名或裁剪正文尾部。

## 可撤回与开关

- 自动从结论写入 `feedback` 类记忆前，须检查「自动记忆」开关（未来可放 `app_settings`）。
- User/Feedback 类默认不随项目导出；若导出需显式勾选。

## 与平台内置策略的关系

平台 JSON 输出契约、日志脱敏等 **不属于** 用户记忆，不可被用户 skill 覆盖。
